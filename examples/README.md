# Simulated face examples

These images are generated by the shared firmware renderer. DEMO is added only
by the host; the physical firmware always displays OPEN BENCH. These are not
photographs or proof of hardware behavior. SETUP / Code 4817 is design-only;
there is no pairing protocol.

From the repository root, regenerate with:

```sh
python3 tools/render_faces_v02.py --snapshot --output examples
```

The command preserves this README and writes source provenance separately to
`RENDER-PROVENANCE.md`.

Native images are 296×128, 1-bit. Files ending @8x.png are 2368×1024
nearest-neighbor previews. The names are armed, held_1840, approved_1840,
held_18400, not_sent_18400, tripped, off, starting, setup.

APPROVED follows a local full-hash release. NOT SENT follows the 60 s expiry.
Neither image proves downstream delivery or a physical refresh/cut time.
